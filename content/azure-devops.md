Microsoft Azure DevOps provides a comprehensive suite of tools and services that enable software teams to plan, develop, test, and deliver high-quality software efficiently. Each service is open and flexible, designed to integrate seamlessly with any application, framework, platform, or cloud. Teams can adopt Azure DevOps as a complete end-to-end solution or use individual services alongside their existing toolchain.

### Azure Boards
Azure Boards provides agile tools to plan, track, and manage work from idea to release. With support for backlogs, boards, sprints, and dashboards, it helps teams stay organized and aligned—whether they use Scrum, Kanban, or a custom process.

### Azure Test Plans
Azure Test Plans helps teams improve software quality with manual, automated, and exploratory testing. It provides tools for test case management, defect tracking, and reporting to support quality at every stage. Fully integrated with Azure DevOps, it links tests to code changes and requirements for a seamless, end-to-end QA process.

### Azure Repos
Azure Repos provides unlimited, cloud-hosted Git repositories that enable seamless collaboration and high-quality code. With features such as pull requests, branch policies, and integrated code reviews, it helps teams manage changes effectively and maintain clean, reliable codebases.

<img src="/images/icons/class.png" alt="Class" title="Training Class"> [Mastering Azure Repos (1 Day)](/mars/)<br/>

### Azure Pipelines
Azure Pipelines delivers fast, flexible CI/CD for building, testing, and deploying applications across any language, platform, or cloud—including on-premises. It streamlines automation and scales to meet the needs of modern DevOps teams.

<img src="/images/icons/class.png" alt="Class" title="Training Class"> [CI/CD Using Azure Pipelines (1 Day)](/cicd/)<br/>

### Azure Artifacts
Azure Artifacts enables teams to create, host, and share packages—such as NuGet, npm, Maven, and Python—within their organization. Fully integrated with Azure DevOps, it supports reliable, versioned dependencies and promotes secure, repeatable builds across projects.

<img src="/images/icons/class.png" alt="Class" title="Training Class"> [Continuous Delivery Using Azure DevOps Services (2 Days)](/cdads/)

### Integrating with GitHub
Azure DevOps and GitHub connect seamlessly. Use GitHub for code and pull requests while tracking progress in Azure Boards. Trigger builds and deployments in Azure Pipelines directly from GitHub commits, and gain full visibility from code to release—all within Azure DevOps.
