<p>RegEx can be a pain. I regularly check out <a href="http://www.regexlib.com/" target="none" rel="noopener">regexlib.com</a> and <a href="http://www.regexadvice.com/" target="none" rel="noopener">regexadvice.com</a>, but <a href="http://staff.newtelligence.net/clemensv" target="none" rel="noopener">Clemens&nbsp;Vasters</a> just pointed out this <a href="http://regex.osherove.com" target="none" rel="noopener">cool, free&nbsp;tool</a> for learning and&nbsp;testing regex. It allows you to build and verify a regular expression against any text input, file or web, and displays matching, splitting or replacement results within an easy to understand, hierarchical tree.<br /></p>
