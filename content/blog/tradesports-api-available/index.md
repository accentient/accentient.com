<p>If you know me, you know my fascination with <a href="http://www.tradesports.com" target="none" rel="noopener">Tradesports.com</a>.</p>
<p>Well, it seems that the parent Company of TradeSports has developed an Application Programmable Interface ("API") that all members of the Exchange are entitled to use subject to satisfying the eligibility criteria. A monthly fee for API access may be charged which may in turn be refunded in full if the member generates sufficient trade volumes.</p>
<p>Visit this <a href="http://www.tradesports.com/aav2/api/" target="none" rel="noopener">page</a> for more information.</p>
