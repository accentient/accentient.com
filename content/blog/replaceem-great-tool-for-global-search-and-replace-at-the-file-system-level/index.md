<p>Every now and then I REALLY need to replace some text with some other text in a whole series of directories.&nbsp; This is especially true when working with MOC course, with LOTS of references to a server name in all sorts of solutions.&nbsp; </p>
<p>There's a GREAT tool that does simple search and replace, through any number or type of files, regardless of directory depth called <a href="http://www.orbit.org/replace/">ReplaceEm</a>.&nbsp; And, it's FREE!&nbsp; The developer just wants you think of <a href="http://www.fitsoftware.com ">FitSoftware</a>&nbsp;when you need some software development done.&nbsp; Download it <a href="http://www.orbit.org/replace/">here</a>.</p>
