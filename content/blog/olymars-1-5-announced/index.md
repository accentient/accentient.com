<p><a href="https://accentient.com/blog/blogs.microsoft.fr/pascalbe/" target="none" rel="noopener">Pascal Belaud</a>, a .NET evangelist at&nbsp;Microsoft France,&nbsp;has&nbsp;started a beta plan for his popular&nbsp;OlyMars product. Version 1.5 will support .NET 2.0 and SQL Server 2005.</p>
<p>So what exactly is&nbsp;<a href="http://www.olymars.net/" target="none" rel="noopener">OlyMars</a>?</p>
<p>It is a&nbsp;SQL Server Centric .Net Code Generator&nbsp;and is a both flexible and powerful generator based on database modeling. It allows instant generation of both T-SQL and .Net code providing a complete library of stored procedures, .NET classes and ready-to-use custom web and form controls related to the database modeling, including associated documentation. These elements are illustrated in two default Windows and Web applications and can be used in custom applications. SQL Server centric .Net code generator is fully extensible to use custom templates and extended properties and consequently can be adjusted to generate any custom code respecting a homogeneous implementation scheme.</p>
