<p>The <em>Developing SharePoint Applications</em> guidance helps architects and developers design and build applications that are both flexible and scalable. It shows developers how to provide IT professionals with the information they need to maintain those applications and diagnose problems when they arise. The guidance also discusses approaches for testing SharePoint applications, such as how to create unit tests, and how to stress and scale test.</p> <p>You can review the guidance project on <a href="http://www.codeplex.com/spg" target="_blank" rel="noopener">CodePlex</a> as well as on <a href="http://www.microsoft.com/spg" target="_blank" rel="noopener">Microsoft’s site</a>. You can download the guidance document (11 mb) <a href="http://www.microsoft.com/downloads/details.aspx?FamilyId=91f3c22c-8be7-4721-9449-84f699337d55&amp;displaylang=en" target="_blank" rel="noopener">here</a>.</p>
