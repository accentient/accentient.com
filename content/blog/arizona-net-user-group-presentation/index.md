<p>Last night I presented a few topics on ADO.NET 2.0 and the SQLCLR to the <a href="http://www.azdnug.com" target="none" rel="noopener">Arizona .NET User Group</a> (<a href="http://www.azdnug.com" target="none" rel="noopener">www.azdnug.com</a>).</p>
<p>It was a fun evening with&nbsp;about 30+ folks in attendance, and all eager to see Whidbey and Yukon in action. I began by explaining what <a href="http://www.microsoft.com/windowsxp/virtualpc" target="none" rel="noopener">VirtualPC</a> is, and why it's important for running alpha and beta software on a production laptop!</p>
<p>I demonstrated 3 areas&nbsp;- (1) drag/drop data-binding, showing the new DbTable, Form DataSources, and DataSet editor,&nbsp;(2) SqlNotification object, allowing a form to be notified when a change to the data has been made on the back-end, and (3) how to create and host a User Defined Function (UDF) in Yukon -- one that was written in VB.NET.</p>
<p>The files for the demonstration (minus Whidbey and Yukon, of course!) can be found <a HREF="/files/azdnugdemo.zip">here</a>.</p>
<p>Everyone, including me, was blown away when they first see this. The integration between Whidbey and Yukon runs very deep, as it witnessed by that 3rd demonstration.</p>
<p>Look for an MSDN article from me on this in the near future.</p>
