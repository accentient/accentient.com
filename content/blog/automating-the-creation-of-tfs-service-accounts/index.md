<p>When setting up new virtual machines for Team Foundation Server 2010, I find myself having to manually create the four amigos: TFSSERVICE, TFSREPORTS, TFSBUILD, and WSSSERVICE (per the <a href="http://www.microsoft.com/downloads/details.aspx?displaylang=en&amp;FamilyID=2d531219-2c39-4c69-88ef-f5ae6ac18c9f" target="_blank" rel="noopener">installation guide</a>). Needless to say, this gets quite old, so I set out to automate this process.</p> <p>First, I checked out <a href="http://blogs.msdn.com/granth" target="_blank" rel="noopener">Grant Holliday</a>’s post from 2007 on <a href="http://ozgrant.com/2007/07/15/hands-free-tfs-install-part-3-installing-team-foundation-server-unattended" target="_blank" rel="noopener">Hands Free TFS Installation</a>. I was only interested in the part where he creates the accounts and sets the permissions. His approach uses a (.bat) batch file, so he’s limited to using "NET USER" commands such as "net user TFSSERVICE * /DOMAIN /ADD /EXPIRES:NEVER". I wanted to specify account description and have more control, so I decided to integrate his ideas with mine into a (.vbs) VBScript file. I also added code to create groups, such as the TFS Administrators group, which I always suggest having.</p> <p><u>1. Download my script</u></p> <p>It’s at the bottom of this post.</p> <p><u>2. Obtain Microsoft’s ntrights.exe utility</u></p> <p>It’s part of the free download of the <a href="http://www.microsoft.com/downloads/details.aspx?FamilyID=9D467A69-57FF-4AE7-96EE-B18C4790CFFD&amp;displaylang=en" target="_blank" rel="noopener">Windows Server 2003 Resource Kit Tools</a>. Download the tools and then install. Since you only need the ntrights.exe tool, it seems silly to install everything else, especially when I try to keep my VMs as small as possible. I used a snapshot VM so I could revert back, then installed the tools, copied out the one file, and reverted. If you trust me, then you can just download the ntrights.zip at the bottom (just don’t tell Microsoft).</p> <p><u>3. Customize the script</u></p> <p>You may want to change the computer name, password, and account names. These are easy search/replace operations.</p> <p><u>4. Keep the files together</u></p> <p>I opted to put the tfsaccounts.vbs and ntrights.exe in the root of C:Program Files for simplicity and to not clutter up my C: root folder.</p> <p>Attachments: <a href="tfsaccounts.zip" target="_blank" rel="noopener">tfsaccounts.zip</a>, <a href="ntrights.zip" target="_blank" rel="noopener">ntrights.zip</a></p>
