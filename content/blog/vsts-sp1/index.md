<p>Team System SP1 is due out...&nbsp; sometime.&nbsp; We still don't have a date from Microsoft (as of 10 Aug 2006), however, <a href="http://blogs.msdn.com/bharry">Brian Harry</a> has provided us with a short list of some of the features to be released.&nbsp; You can read about it <a href="http://blogs.msdn.com/bharry/archive/2006/06/15/632236.aspx">here</a>.</p>
<p>My favorite new feature is WIT Custom Controls.&nbsp; This means we'll finally be able to host a control that will display custom data without having to rebuild the entire Work Item display framework.&nbsp; Very cool.&nbsp; A few already pop to mind:&nbsp; a Grid display, graphical displays (small embedded charts), and maybe even a tiny Wiki.&nbsp; </p>
