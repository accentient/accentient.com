<br />It was a simple enough question that Ethan, my .NET remoting student,&nbsp;asked me yesterday. I did some research, and couldn't find anything official from Microsoft, just their <a href="http://msdn.microsoft.com/library/default.asp?url=/library/en-us/cpgenref/html/gngrfaspnetconfigurationsectionschema.asp" target="none" rel="noopener">human readable schema</a> on MSDN. Then I found <a href="http://www.radsoftware.com.au/articles/intellisensewebconfig.aspx" target="none" rel="noopener">radsoftware's page</a>, which offers a product providing Intellisense to your VS.NET 1.X&nbsp;config file editor. About half way down the page is a ZIP file containing an XSD&nbsp;schema that they built. It looks pretty thorough, but I sent off an email just to make sure.<br />
