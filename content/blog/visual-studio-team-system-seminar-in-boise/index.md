<p>If you attend, you can see how VSTS includes an integrated team server and customizable processes to help teams drive predictability, visibility, and control into their software development process. This seminar will provide an overview of features for project managers, business analysts, software architects and developers, database professionals, and software testers. </p>

<ul>

<li>Day 2 -&nbsp;VSTS databases, testing, reports, and customization</li></ul>
