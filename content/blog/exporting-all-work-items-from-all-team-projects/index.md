<p>Somebody asked me a simple question the other day: "how do I export <em>all</em> of my work items at once". I suspected they were looking to perform a backup, but it sounded like they might want to import into another system or just archive them in some readable way. I suggested Microsoft Excel, but it can only fetch work items from one team project at a time. So repetition, using a Macro or a human, would be required.</p> <p>Here’s an alternative we came up with …</p> <p>1. Downloaded and installed <a href="http://msdn.microsoft.com/en-us/teamsystem/bb980963.aspx" target="_blank" rel="noopener">Team Foundation Power Tools</a>.</p> <p>2. Picked one of the Team Projects, added a query, and removed the <strong>Team Project = @Project</strong> clause, so that it was completely empty:</p> <p>&nbsp;&nbsp;&nbsp; <img style="border-right-width: 0px; display: inline; border-top-width: 0px; border-bottom-width: 0px; border-left-width: 0px" title="Work Item Query" border="0" alt="Work Item Query" src="image_8.png" width="445" height="83"> </p> <p>3. Changed the <strong>Column Options</strong>, added the columns we wanted to export. For testing, we selected ID, Team Project, Work Item Type, and Title.</p> <p>&nbsp;&nbsp;&nbsp; <img style="border-right-width: 0px; display: inline; border-top-width: 0px; border-bottom-width: 0px; border-left-width: 0px" title="image" border="0" alt="image" src="image_11.png" width="489" height="347">&nbsp;&nbsp; </p> <p>4. Ran the query and verified that it pulled the right work items and fields we wanted.</p> <p>5. Saved the query (My query) and named it <strong>AllProjectWorkItems</strong>.</p> <p>&nbsp;&nbsp;&nbsp; <img style="border-right-width: 0px; display: inline; border-top-width: 0px; border-bottom-width: 0px; border-left-width: 0px" title="image" border="0" alt="image" src="image_14.png" width="359" height="340"> </p> <p>6. Dropped to the command prompt and executed the following commands:</p> <p><font face="Courier New"><strong>&nbsp;&nbsp;&nbsp; cd c:Program FilesMicrosoft Team Foundation Server 2008 Power Tools </strong></font> <p><strong><font face="Courier New">&nbsp;&nbsp;&nbsp; tfpt query "CalculatorMy QueriesAllProjectWorkItems" /Server:vsts /format:xml &gt; c:AllWorkItems.xml</font> </strong> <p>&nbsp; <p>7. This command generated an XML file containing all of the fields from all work items from all projects. This satisfied their requirement.</p> <p>&nbsp;&nbsp;&nbsp; <img style="border-right-width: 0px; display: inline; border-top-width: 0px; border-bottom-width: 0px; border-left-width: 0px" title="image" border="0" alt="image" src="image_17.png" width="651" height="311"> </p> <p>At this point you can update the query adding more columns, until you have the superset of what you need for the export of all types from all projects. With a little finesse, the XML document could be migrated into Excel or another software application.</p>
