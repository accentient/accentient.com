<a href="http://blog.hundhausen.com">Richard Hundhausen</a> is talking about SQL Management Objects (SMO).  Started on a high note.  Good jokes.  Got the audience interested.

&nbsp;

High points:

&nbsp;

&nbsp;
<ul>
<ul>
	<li>You can capture your clicks, and turn them into a script that can be edited.</li>
</ul>
</ul>
&nbsp;
<ul>
<ul>
	<li>SMO is backward compatible with SQL Server 2000 and 7.0!</li>
</ul>
</ul>
&nbsp;
<ul>
<ul>
	<li>Over 500 classes in SMO, with over 19,000 methods, properties, constructors, fields and events</li>
</ul>
</ul>
&nbsp;
<ul>
<ul>
	<li>Can use What-If to see what would happen if you ran something.  You get the SQL but don't HAVE to get the results of running it.</li>
</ul>
</ul>
