<p>Over the years, we've had a few clients automate their build process by using <a href="http://www.finalbuilder.com" target="none" rel="noopener">Final Builder</a> by VSoft Technologies. Much like Team (Foundation) Build, Final Builder&nbsp;is a powerful build &amp; release management tool. Unlike Team Build, Final Builder has a slick UI allowing a build master to quickly design the builds.</p>
<p>Last summer, a new Final Builder version (4.2)&nbsp;was release which included more support for MSBuild and Team Build tasks. With that version, and following the guidance in&nbsp;<a href="http://www.finalbuilder.com/articles.aspx?mid=370&amp;ctl=ArticleView&amp;articleId=20" target="none" rel="noopener">this article</a>, you can get the two products working together!</p>
