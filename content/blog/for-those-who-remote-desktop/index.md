<p>While enjoying the fireworks yesterday in Oceanside, California with my friend <a title="Scott Cate's Blog" href="http://weblogs.asp.net/scottcate" target="_blank" rel="noopener">Scott Cate</a>, he let&nbsp;me know about a CodePlex project called <a href="http://www.codeplex.com/Terminals" target="_blank" rel="noopener">Terminals</a>.</p> <p>Terminals is simply a wrapper, around the Terminal Services ActiveX Client (mstscax.dll) and provides multi-tab interface - which can be very handy when remoted-in to multiple servers at once. Also, it supports screen resolution up to 4096x2048, clipboard, drag &amp; drop into the session, and some other nice features.</p>
