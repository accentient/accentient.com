<p>MSDN subscription customers can download from the MSDN subscriber download site</p>
<p><a href="http://blogs.msdn.com/jeffbe/" target="none" rel="noopener">Jeff Beehler</a> posted these instructions to upgrade from Beta3/Refresh:</p>
<ol>
<li>Backup your server and copy the data to a safe location</li>
<li>Download the Team Foundation Server RC</li>
<li>Download the <a href="http://go.microsoft.com/fwlink/?LinkID=60341">Upgrade Utility</a></li>
<li>Uninstall Team Foundation Server Beta 3 Refresh</li>
<li>Follow the upgrade instructions, which are included with the Upgrade Utility</li>
<li>Install Team Foundation Server RC</li>
<li>Complete the post install upgrade instructions, which are included with the Upgrade Utility</li></ol>
<p>For a reference to the major changes since Beta3 refresh, please see <a href="http://blogs.msdn.com/jeffbe/archive/2006/01/22/515917.aspx" target="none" rel="noopener">Jeff's posting</a>.<br /></p>
