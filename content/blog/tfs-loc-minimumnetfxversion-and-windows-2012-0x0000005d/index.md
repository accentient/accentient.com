<p>A tale of two error in the path to RC install.</p> <p>I wanted to install the RC of TFS2012 to do some upgrade proving. To&nbsp; keep up to date the target is Windows Server 2012, running SQL 2012, and TFS2012 on VMWare Workstation 8.0.</p> <p>To keep it light to start with – no SharePoint.</p> <p>So I rolled out my Windows 2012 Server Beta and got the error:</p> <p><a href="https://accentient.com/blog/content/binary/TFS_F5E4/image_2.png"><img style="display: block; max-width: 100%; height: auto; margin-bottom: 1rem; border: 1px solid black; box-shadow: 2px 2px 10px rgba(0,0,0,0.5);" title="image" border="0" alt="image" src="https://accentient.com/blog/content/binary/TFS_F5E4/image_thumb.png" width="322" height="307"></a></p> <p>Digging through the logs it was failing at the .NetFX check. After a bit of thinking and checking that the latest version of .NET 4.5 was installed, it hit me that the TFS 2012 RC would not run on the Windows Server 2012 Beta.</p> <p>OK. So I needed to install Windows Server 2012 RC. The Beta was not an issues, so I spun up a new VM pointing to the ISO and got the semi-infamous 0x0000005D error</p> <p><a href="https://accentient.com/blog/content/binary/TFS_F5E4/image_4.png"><img style="display: block; max-width: 100%; height: auto; margin-bottom: 1rem; border: 1px solid black; box-shadow: 2px 2px 10px rgba(0,0,0,0.5);" title="image" border="0" alt="image" src="https://accentient.com/blog/content/binary/TFS_F5E4/image_thumb_1.png" width="381" height="246"></a></p> <p>So I Googled it with Bing, and got some hits. A great post by Pete Long here <a title="http://www.petenetlive.com/KB/Article/0000618.htm" href="http://www.petenetlive.com/KB/Article/0000618.htm">http://www.petenetlive.com/KB/Article/0000618.htm</a> put me on the right path. Windows Server 2012 RC has a requirement for the Data Execution Prevention (aka No Execute Memory Protection) to be enabled.</p> <p>To check if it is on your machine, follow the instructions here <a title="http://support.microsoft.com/kb/912923" href="http://support.microsoft.com/kb/912923">http://support.microsoft.com/kb/912923</a></p> <p>This was drawing a blank, so I contacted the manufacturer of the laptop I use, and they pointed me to a BIOS update by Compal. </p> <p>I needed a light boot from a USB flash drive, and found this page which has a light utility that will create a small footprint bootable USB <a title="http://www.biosflash.de/e/bios-boot-usb-stick.htm" href="http://www.biosflash.de/e/bios-boot-usb-stick.htm">http://www.biosflash.de/e/bios-boot-usb-stick.htm</a>. Booting from that I simply ran the batch file provided from the Compal update which updated the BIOS of the machine (after a backup of the BIOS and key data for safety), and then installed Windows Server 2012.</p> <p>TFS flew on, after doing the SQL install following Stuart Preston’s easy one-liner from <a title="http://stuartpreston.net/blog/2012/04/06/automated-installation-of-sql-server-2012-for-tfs-11-at-the-command-line/" href="http://stuartpreston.net/blog/2012/04/06/automated-installation-of-sql-server-2012-for-tfs-11-at-the-command-line/">http://stuartpreston.net/blog/2012/04/06/automated-installation-of-sql-server-2012-for-tfs-11-at-the-command-line/</a></p> <p><strong>Note:</strong> With VMWare workstation 8 – you must disable the VMware tools, and watch as it will try to install them, even though you have asked it not to! Cancel as soon as you see them pop up, or the VM will hang in an unknown state.</p> <p><a href="https://accentient.com/blog/content/binary/TFS_F5E4/image_6.png"><img style="display: block; max-width: 100%; height: auto; margin-bottom: 1rem; border: 1px solid black; box-shadow: 2px 2px 10px rgba(0,0,0,0.5);" title="image" border="0" alt="image" src="https://accentient.com/blog/content/binary/TFS_F5E4/image_thumb_2.png" width="564" height="348"></a></p> <p>Now to get on and experiment with the working setup!</p>
