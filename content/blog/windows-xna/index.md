<p>No, not Windows&nbsp;DNA, but <a href="http://www.microsoft.com/xna/" target="none" rel="noopener">XNA</a>. Yes, it's an exciting new enhancement to DCOM bringing&nbsp;XML manifests and BizTalk schemas! Kidding ...</p>
<p>Microsoft XNA&nbsp;is a tool and set of technologies which will help game studios manage the growing complexities of their game content builds. Basically, it is&nbsp;designed to help game studios and publishers develop better games, more effectively, on all platforms. Microsoft unveiled the XNA Framework at the <a href="http://www.gdconf.com/" target="none" rel="noopener">Game Developers Conference 2006</a>.</p>
<p>Best yet, <a href="http://go.microsoft.com/fwlink/?linkid=63417&amp;clcid=0x409" target="none" rel="noopener">XNA Studio</a> is based on Microsoft Visual Studio 2005 <a href="http://msdn.microsoft.com/teamsystem" target="none" rel="noopener">Team System</a>. XNA Studio will <a href="http://msdn.microsoft.com/vstudio/extend/" target="none" rel="noopener">extend</a> and customize Visual Studio 2005 Team System to make it an ideal solution for game studios and publishers.</p>
