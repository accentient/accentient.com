<p>Call it a code generator, software factory, or just a clever script. If you can write code that writes code - you win, even if just a small victory for humans in this contest&nbsp;we call software development.</p> <p>For example, I've been working on an ASP.NET application which contains many data entry screens. You know the kind:&nbsp;very simple, table-format with a label and a textbox of&nbsp;a certain width, that may or may not require&nbsp;some validation. In other words, a whole lot of markup like this:</p> <p><font face="Courier New">&lt;tr&gt;</font> <p><font face="Courier New">&nbsp; &lt;td class="EditLabel"&gt;Number&lt;/td&gt;</font> <p><font face="Courier New">&nbsp; &lt;td class="Edit"&gt;</font> <p><font face="Courier New">&nbsp;&nbsp;&nbsp; &lt;asp:TextBox ID="txtNumber" runat="Server" Width="200px" MaxLength="20"&gt;&lt;/asp:TextBox&gt;</font> <p><font face="Courier New">&nbsp; &lt;/td&gt;</font> <p><font face="Courier New">&lt;/tr&gt;</font> <p><font face="Courier New"></font>&nbsp; <p>Now, if you have to type the above more than once or twice, you will go insane (been there,&nbsp;gone there). More importantly, you will probably introduce a bug or two. So, I opened up SQL Server 2005 Management Studio and wrote the following T-SQL code:</p> <p><font face="Courier New">USE SomeDB</font> <p><font face="Courier New">GO</font> <p><font face="Courier New"></font>&nbsp; <p><font face="Courier New">DECLARE @Table&nbsp; varchar(128)</font> <p><font face="Courier New">DECLARE @Column varchar(128)</font> <p><font face="Courier New">DECLARE @Width&nbsp; varchar(10)</font> <p><font face="Courier New">DECLARE @Length int</font> <p><font face="Courier New">DECLARE @Type&nbsp;&nbsp; int</font> <p><font face="Courier New"></font>&nbsp; <p><font face="Courier New">SET @Table = 'Employer' -- Pass this as a parameter</font> <p><font face="Courier New"></font>&nbsp; <p><font face="Courier New">DECLARE ColumnCursor CURSOR FOR</font> <p><font face="Courier New">&nbsp;&nbsp; SELECT C.Name, C.Max_Length, C.User_Type_ID FROM Sys.Columns C</font> <p><font face="Courier New">&nbsp;&nbsp; INNER JOIN Sys.Tables T ON C.Object_ID = T.Object_ID</font> <p><font face="Courier New">&nbsp;&nbsp; WHERE T.Name = @Table</font> <p><font face="Courier New">&nbsp;&nbsp; ORDER BY Column_ID</font> <p><font face="Courier New"></font>&nbsp; <p><font face="Courier New">OPEN ColumnCursor</font> <p><font face="Courier New"></font>&nbsp; <p><font face="Courier New">FETCH NEXT FROM ColumnCursor INTO @Column, @Length, @Type</font> <p><font face="Courier New">WHILE @@FETCH_STATUS = 0</font> <p><font face="Courier New">BEGIN</font> <p><font face="Courier New">&nbsp; IF @Type &lt;&gt; 36 -- No GUIDs</font> <p><font face="Courier New">&nbsp; BEGIN</font> <p><font face="Courier New">&nbsp;&nbsp;&nbsp; IF @Length &lt; 0 SET @Length = 100</font> <p><font face="Courier New">&nbsp;&nbsp;&nbsp; IF @Length &lt; 10</font> <p><font face="Courier New">&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; SET @Width = '50px'</font> <p><font face="Courier New">&nbsp;&nbsp;&nbsp; ELSE IF @Length &lt; 20</font> <p><font face="Courier New">&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;SET @Width = '100px'2013-08-28 18:34:09'</font> <p><font face="Courier New">&nbsp;&nbsp;&nbsp; ELSE IF @Length &lt; 50</font> <p><font face="Courier New">&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; SET @Width = '200px'</font> <p><font face="Courier New">&nbsp;&nbsp;&nbsp; ELSE IF @Length &lt; 100</font> <p><font face="Courier New">&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; SET @Width = '300px'</font> <p><font face="Courier New">&nbsp;&nbsp;&nbsp; ELSE</font> <p><font face="Courier New">&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; SET @Width = '400px'</font> <p><font face="Courier New"></font>&nbsp; <p><font face="Courier New">&nbsp;&nbsp;&nbsp; PRINT '&lt;tr&gt;'</font> <p><font face="Courier New">&nbsp;&nbsp;&nbsp; PRINT '&nbsp; &lt;td class="EditLabel"&gt;' + @Column + '&lt;/td&gt;'</font> <p><font face="Courier New">&nbsp;&nbsp;&nbsp; PRINT '&nbsp; &lt;td class="Edit"&gt;'</font> <p><font face="Courier New">&nbsp;&nbsp;&nbsp; PRINT '&nbsp;&nbsp;&nbsp; &lt;asp:TextBox ID="txt' + @Column + '" runat="Server" Width="' + @Width + '" MaxLength="' + CONVERT(varchar(10),@Length) + '"&gt;&lt;/asp:TextBox&gt;'</font> <p><font face="Courier New">&nbsp;&nbsp;&nbsp; PRINT '&nbsp; &lt;/td&gt;'</font> <p><font face="Courier New">&nbsp;&nbsp;&nbsp; PRINT '&lt;/tr&gt;'</font> <p><font face="Courier New">&nbsp; END</font> <p><font face="Courier New">&nbsp; FETCH NEXT FROM ColumnCursor INTO @Column, @Length, @Type</font> <p><font face="Courier New">END</font> <p><font face="Courier New"></font>&nbsp; <p><font face="Courier New">CLOSE ColumnCursor</font> <p><font face="Courier New">DEALLOCATE ColumnCursor</font> <p><font face="Courier New"></font>&nbsp; <p>You get the picture. Feel free to customize this code to introduce additional formatting, a slick UI, or other business rules to the mix.</p>
