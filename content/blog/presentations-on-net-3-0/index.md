<p>A PowerPoint deck introducing .NET 3.0 has been uploaded to the presentations area of the <a href="http://www.netfx3.com" target="none" rel="noopener">.NET Framework 3.0 site</a>.</p>
<p>Although it's still pre-release (release candidate 1 is available for download), the new&nbsp;.NET Framework 3.0 looks very promising as the&nbsp;new managed code programming model for Windows. It will combine the power of the .NET Framework 2.0 with new technologies for building applications that have visually compelling user experiences (WPF), seamless communication across technology boundaries (WCF), and the ability to support a wide range of business processes (WF).</p>
<p>Here's a direct <a href="http://wf.netfx3.com/files/folders/presentations/entry6677.aspx" target="none" rel="noopener">link</a> to the slide deck introducing .NET 3.0, as well as intro decks of <a href="http://wf.netfx3.com/files/folders/presentations/entry6672.aspx" target="none" rel="noopener">WF</a>, <a href="http://wpf.netfx3.com/files/folders/presentations/entry1927.aspx" target="none" rel="noopener">WPF</a>, <a href="http://wcf.netfx3.com/files/folders/teched_2006_chalk_talks/entry6680.aspx" target="none" rel="noopener">WCF</a>, and <a href="http://cardspace.netfx3.com/files/folders/powerpoint/entry5122.aspx" target="none" rel="noopener">CardSpace</a>.</p>
<p>As a follow-up, you can also find some good .NET 3.0 presentations at <a href="http://www.dotnet-u.com/" target="none" rel="noopener">.NET University</a>.</p>
