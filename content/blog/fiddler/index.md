<p>A few weeks ago a student told me about <a href="http://www.fiddlertool.com" target="none" rel="noopener">Fiddler</a>, which is a cool&nbsp;HTTP Debugging Proxy. It logs all HTTP traffic between your computer and an endpoint. It event includes a JScript.NET event-based scripting subsystem.</p>
