<p>Microsoft released WSE 2.0 on Monday. I heard about it at Tech-Ed from fellow Candian Regional Director <a href="http://bristowe.com/blog" target="none" rel="noopener">John Bristowe</a>.</p>
<p>Go and download the <a href="http://www.microsoft.com/downloads/details.aspx?FamilyId=FC5F06C5-821F-41D3-A4FE-6C7B56423841&amp;displaylang=en" target="none" rel="noopener">Web Services Enhancements (WSE) 2.0 for Microsoft .NET</a> and start using WS-Security (OASIS 2004 standard), WS-Policy, WS-SecurityPolicy, WS-Trust, WS-SecureConversation and WS-Addressing.</p>
