<p>We all have our favorite database structure generator or schema reporting tool. Maybe we&nbsp;have built one&nbsp;of them in the past. I always tell my clients that it's a great "first application" to build when learning <a href="http://msdn2.microsoft.com/en-us/library/ms162169.aspx" target="none" rel="noopener">SQL Management Objects</a> (SMO).</p>
<p>I just found out about <a href="http://www.elsasoft.org/" target="none" rel="noopener">SqlSpec</a>.</p>
<p>SqlSpec generates documentation in two formats: HTML or CHM. I particularly like the CHM format,&nbsp;especially&nbsp;when&nbsp;you want a single, compact file containing all your documentation about one or more databases. The CHM is indexed so it is easily searchable for any keyword. If you visit their <a href="http://www.elsasoft.org/samples.htm" target="none" rel="noopener">Samples</a> page, you can see what these CHM files look like.</p>
<p>Naturally, SqlSpec&nbsp;supports SQL Server and Analysis Services, but also other legacy databases like Oracle,&nbsp;MySQL, and Access. It's $149 and they have&nbsp;a free trial version.</p>
<p>Pretty slick.</p>
