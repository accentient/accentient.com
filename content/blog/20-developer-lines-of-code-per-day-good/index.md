<p>Up front:&nbsp; I believe that Lines of Code is a USELESS metric.&nbsp; However, people are often shocked by the raw number of lines of code that are written each day by a developer.&nbsp; What's your guess?&nbsp; 1,000?&nbsp; 200?&nbsp; <strong>Try just under 20</strong>.&nbsp; This is basically the number of lines of code in a released project divided by the number of programmer days, so, just because you can write 1,000 buggy lines of code per day, that doesn't make you productive!&nbsp; :-)&nbsp; It's the post bug-fix, post integration testing, post-everything lines that count.&nbsp; (You can find some background <a href="http://en.wikipedia.org/wiki/Source_lines_of_code">here</a>&nbsp;and <a href="http://www.dwheeler.com/sloc/redhat71-v1/redhat71sloc.html">here</a>.)</p>
