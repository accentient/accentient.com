<p><a href="http://www.devbiz.com/teamplain/webaccess/" target="none" rel="noopener">TeamPlain Web Access</a> is a web interface for Team Foundation Server that allows you to manage work items, documents, reports and source control repositories.</p>
<p>These guys also make a Team System plug-in for <a href="http://www.devbiz.com/teamplain/eclipse/" target="none" rel="noopener">Eclipse</a> and <a href="http://www.devbiz.com/teamplain/vsnet/" target="none" rel="noopener">Visual Studio 2003</a>.<br /></p>
