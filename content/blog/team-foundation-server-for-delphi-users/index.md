<p>This question was recently <a href="http://forums.microsoft.com/MSDN/ShowPost.aspx?PostID=216167&amp;SiteID=1" target="none" rel="noopener">asked</a> on the <a href="http://forums.microsoft.com/MSDN/default.aspx?ForumGroupID=5&amp;SiteID=1" target="none" rel="noopener">VSTS forums</a>.</p>
<p>As <a href="http://blogs.msdn.com/robcaron" target="none" rel="noopener">Rob Caron</a> explains, the integration depends solely on Borland's ability to integrate TFS into Delphi's IDE. Until then options include using the standalone Team Explorer, command-line utilities, or possibly the newly available <a href="http://www.microsoft.com/downloads/details.aspx?familyid=32202966-EF04-442F-8C5C-88BDF15F551C&amp;displaylang=en" target="none" rel="noopener">MSSCII Provider</a> for Team Foundation Server.</p>
