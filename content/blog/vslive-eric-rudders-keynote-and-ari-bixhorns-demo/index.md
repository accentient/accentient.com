<p>Eric's speaking on lots of overview stuff, with just enough technical info to keep it interesting and enough business information to get my juices flowing.</p>
<p>Indigo Day Theme - What should you do today, to prepare for Web Services in the future?</p>
<p>Notes:</p>
<ul>
<li>W3C recommendations are improving, including MTOM and WS-AtomicTransactions.
<li>Indigo's 3 areas: <em>Productivity</em> (attribute based, VS integration), <em>Interoperability</em> (WS-* specs), and <em>Service-Oriented Development</em> (loosely coupled, config based communication)
<li>Lots of focus on the Service Oriented Architecture (SOA) support in Indigo.
<li>Indigo services will be built using VS 2005.&nbsp; Indigo is an extension of the .NET Framework.</li></ul>
<p>Ari Bixhorn's up for a demo.&nbsp; Got a big ol' bandage on his head.&nbsp; The demo's focused on a hospital experience.&nbsp; (Whoops, it's not a bandage, it'2013-08-28 13:52:37's the heart rate monitor.)</p>
<ul>
<li>Lots of drag/drop, graphical functionality.
<li>Pretty cool demo, with a heart rate and brain wave monitor.
<li>Fun demo to watch.&nbsp; He's changing the Web Services to go over HTTP from TCP.
<li>Now packets are being dropped, since it's HTTP over several intermediaries.&nbsp; So, we need reliability.
<li>He simply adds the reliability attribute (and a security attribute) and bingo!&nbsp; :-)
<li>Also, changes the security model using a simple config file.&nbsp; This follows the good SOA model of changing non-business logic stuff in the configuration, not the code.</li></ul>
<p>Eric's Back Up:</p>
<ul>
<li>BizTalk isn't going away
<ul>
<li>2005 - WSE 1.0 Support
<li>2006 - Adapter for Indigo
<li>Beyond - BizTalk will use Indigo as its foundation</li></ul>
<li>SQL Server
<ul>
<li>Currently - some support
<li>Later - Indigo programming model layered over Service Broker
<li>SQL Server vNext - Service Broker uses Indogo transports for WS-* interop</li></ul>
<li>Windows Sharepoint Services will have a consistent Web Services infrastructure in the future
<li>VSIP program - 225 Premier and Alliance Partners, and 20,000 affiliates.&nbsp; Yep, the extensibility ROCKS!
<li>VS2005 Beta2 will be released in March ("maybe not until March 38th or March 45th...")</li></ul>
