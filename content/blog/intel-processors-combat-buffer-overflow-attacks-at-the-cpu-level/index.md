<p>Certain Intel processors implement the Execute Disable Bit functionality, thus preventing certain classes of malicious &#8220;buffer overflow&#8220; attacks -- when combined with a supported operating system. Although not a new technology, Intel is aggresively providing end-to-end workstations and servers this year.</p>
<p>Execute Disable Bit currently requires one of the following operating systems to support it:</p>
<ul>
<li>Microsoft Windows Server 2003 with Service Pack 1
<li>Microsoft Windows XP with Service Pack 2</li></ul>
