I've posted about this before, however, it's so important I'll repost.&nbsp; If you're trying to create a listener web service for TFS events, don't start from scratch!&nbsp; Use <a href="http://blogs.conchango.com/howardvanrooijen/default.aspx">Howard van Rooijen</a>'s <a href="http://blogs.conchango.com/howardvanrooijen/archive/2006/04/29/3894.aspx">VS2005 template</a>.&nbsp; It will create the web services, along with the appropriate signatures, as well as convert the events to an object, so that you can effectively use it.&nbsp; <br />
