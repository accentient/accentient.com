<p>One of the coolest controls that Visual Studio 2005 includes is the&nbsp;report design and view functionality of the&nbsp;ReportViewer controls. What used to be a server-only function,&nbsp;.RDL (now&nbsp;.RDLC) files can be rendered client-side by Web or Windows applications with this control. Reports&nbsp;can contain tabular, aggregated, and multidimensional data.</p>
<p>Thanks to <a href="http://www.solidqualitylearning.com.au/ourpeople.aspx" target="none" rel="noopener">Peter Myers</a> for pointing me to <a href="http://www.gotreportviewer.com/" target="none" rel="noopener">this site</a> to answer all of my (and your) questions and help unlock the hidden potential of the <a href="http://msdn2.microsoft.com/en-us/library/ms251671(en-US,VS.80).aspx" target="none" rel="noopener">ReportViewer</a> control.</p>
