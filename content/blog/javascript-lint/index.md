<p>If you hate coding JavaScript as much as I do, then you'll appreciate the 'lint tools. </p>
<p>Microsoft doesn't have a good JavaScript (JScript) IDE, and many JavaScript environments&nbsp;do not warn against questionable coding practices. It can be a nightmare when you actually want to write quality, maintainable code. That's where <a href="http://www.javascriptlint.com/" target="none" rel="noopener">JavaScript Lint</a> comes in. With JavaScript Lint, you can check all your JavaScript source code for common mistakes without actually running the script or opening the web page.</p>
<p>There's a <a href="http://www.javascriptlint.com/download.htm" target="none" rel="noopener">downloadable</a> lint for Windows as well as an <a href="http://www.javascriptlint.com/online_lint.php" target="none" rel="noopener">online version</a> for pasting and checking snippets.</p>
