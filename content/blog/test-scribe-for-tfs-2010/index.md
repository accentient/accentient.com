<p>This tool popped-up today during our Scrum Developer trainer-prep in Sydney. One of the teams decided to be over-achievers and delivered their test cases (and results) in a nice Word document format. Turns out they used this <a href="http://visualstudiogallery.msdn.microsoft.com/en-us/d18873c7-909d-4788-a56e-0c496a1d8bb9" target="_blank" rel="noopener">Test Scribe</a> tool available on the Visual Studio Gallery. Although in a pre-release version, it worked pretty good and generated some nice-looking </p> <p>Test Scribe is a tool for generating documentation about TCM (Test Case Management) artifacts. Testers can use a stand-alone client to connect to a TFS 2010 server/project. With a Test Plan selected, users are able to generate a Test Plan Document, including information about the plan, the suite hierarchy, and each test case contained in the suites. <p>&nbsp; <p>Looks like there might be some issues with using it SxS with VS 2008.</p>
