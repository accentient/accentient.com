<p>Thanks to <a href="http://blogs.msdn.com/bharry" target="none" rel="noopener">Brian Harry</a> and team for <a href="http://blogs.msdn.com/bharry/archive/2006/12/20/new-tfs-tools-available.aspx" target="none" rel="noopener">releasing</a> the latest version of the provider.</p>
<p>The enhancements in this latest release include:</p>
<ul>
<li>Enable handling branched solutions in Visual Studio 2003</li>
<li>Fixed issues to enable provider to support TOAD for SQL Server 2.0</li>
<li>Enhanced the "Choose Folder in Team Foundation Server" dialog</li>
<li>Fixed bug which prevented Properties Dialog from displaying local path</li>
<li>Work Items Query list in the Checkin Dialog is loaded and saved on the disk</li>
<li>"Get" operation performance improvements</li>
<li>Miscellaneous bug fixes</li></ul>
<p>Download the new provider <a href="http://www.microsoft.com/downloads/details.aspx?familyid=87E1FFBD-A484-4C3A-8776-D560AB1E6198&amp;displaylang=en" target="none" rel="noopener">here</a>, and remember it&nbsp;is for use by anyone who owns a Team Foundation Server Client Access License (CAL).</p>
