<h1>Tracking waste in TFS</h1> <h2>Overview</h2> <p>Tracking waste and gathering the empirical data is one of the most effective ways of convincing people for the need to adapt.  <p>This needs an Estimated Effort field, as in Scrum for Team System template.  <p>This can be done with the MS templates, by adding this field in.  <p>You need to use the estimated effort field, so that the burndown is not affected.  <h2>Steps</h2> <p>Within the area path of the team project, create a top level area called waste, under that add the key waste areas as you become aware of them  <p><a href="clip_image001_2.png"><img style="display: block; max-width: 100%; height: auto; margin-bottom: 1rem; border: 1px solid black; box-shadow: 2px 2px 10px rgba(0,0,0,0.5);" title="clip_image001" border="0" alt="clip_image001" src="clip_image001_thumb.png" width="244" height="198"></a>  <p>Whenever a team member encounters an issue that is causing them to lose time, they create a Task (Sprint Backlog Task in SfTS 3) and set the Area path (feature scope in SfTS 3) to be waste and the sub area if known.  <p>Then update the estimated effort with the amount of time lost.  <p><a href="clip_image002_2.png"><img style="display: block; max-width: 100%; height: auto; margin-bottom: 1rem; border: 1px solid black; box-shadow: 2px 2px 10px rgba(0,0,0,0.5);" title="clip_image002" border="0" alt="clip_image002" src="clip_image002_thumb.png" width="625" height="188"></a>  <p>Set  <p>Estimated Effort = time lost  <p>Planning scope/Iteration Path = sprint  <p>Work Remaining = 0  <p>Feature Scope/Area Path = WasteSubArea  <p>Description = Meaningful comment  <p>Title = Meaningful Title  <p>Create a separate work items or update the work item as and when further waste is identified.  <h2>Reporting</h2> <p>Create a new work item query, and save it with a meaningful name. I have used "Waste Query"  <p><a href="clip_image003_2.png"><img style="display: block; max-width: 100%; height: auto; margin-bottom: 1rem; border: 1px solid black; box-shadow: 2px 2px 10px rgba(0,0,0,0.5);" title="clip_image003" border="0" alt="clip_image003" src="clip_image003_thumb.png" width="632" height="109"></a>  <p>Add the columns that you want to report on, by editing the column options. I have added the Estimated Effort and Area Path columns  <p><a href="clip_image004_2.png"><img style="display: block; max-width: 100%; height: auto; margin-bottom: 1rem; border: 1px solid black; box-shadow: 2px 2px 10px rgba(0,0,0,0.5);" title="clip_image004" border="0" alt="clip_image004" src="clip_image004_thumb.png" width="398" height="308"></a>  <p>After saving the query, you can then open it up in excel and create a report with a pivot table and a chart to help create transparency regarding waste  <p><a href="clip_image005_2.png"><img style="display: block; max-width: 100%; height: auto; margin-bottom: 1rem; border: 1px solid black; box-shadow: 2px 2px 10px rgba(0,0,0,0.5);" title="clip_image005" border="0" alt="clip_image005" src="clip_image005_thumb.png" width="394" height="368"></a>  <h2>Other Process Templates</h2> <p>For this to work with other process templates, you will need to add in an "Estimated Effort" field to the Task work item</p> <p>1.
