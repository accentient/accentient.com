<p>Over the weekend&nbsp;Microsoft released some cool add-ins for Excel 2007 and Visio 2007:</p>
<ul>
<li><strong>Table Analysis Tools for Excel</strong> - this add-in provides you with easy-to-use tasks that leverage SQL Server 2005 Data Mining under the covers to perform powerful analytics on your spreadsheet data.</li>
<li><strong>Data Mining Client for Excel</strong>&nbsp;-&nbsp;This add-in allows you to go through the full data mining model development lifecycle within Excel 2007 using either your spreadsheet data or external data accessible through your SQL Server 2005 Analysis Services instance.</li>
<li><strong>Data Mining Templates for Visio</strong> - This add-in allows you to render and share your mining models as annotatable Visio 2007 drawings.</li></ul>
<p>Download the new add-ins <a href="http://www.microsoft.com/downloads/details.aspx?FamilyID=7c76e8df-8674-4c3b-a99b-55b17f3c4c51&amp;DisplayLang=en" target="none" rel="noopener">here</a>.</p>
