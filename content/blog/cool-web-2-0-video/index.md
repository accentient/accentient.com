<p>You've probably heard of "Web 2.0", but what is it? According to <a href="http://en.wikipedia.org/wiki/Web_2" target="none" rel="noopener">Wikipedia</a> and <a href="http://www.oreillynet.com/pub/a/oreilly/tim/news/2005/09/30/what-is-web-20.html" target="none" rel="noopener">O'Reilly</a>, Web 2.0 "refers to a perceived second-generation of Web-based services—such as social networking sites, wikis, communication tools, and folksonomies." I love that last word!</p>
<p>Here's a cool, short <a href="http://youtube.com/watch?v=6gmP4nk0EOE" target="none" rel="noopener">video</a> from <a href="http://www.ksu.edu/sasw/anthro/wesch.htm" target="none" rel="noopener">Michael Wesch</a>, assistant professor of Cultural Anthropology at Kansas State Univerisity, which puts it into terms we can all understand.</p>
