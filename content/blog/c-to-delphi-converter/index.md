<p><a href="http://dotnet.borland.com/babelcode" target="none" rel="noopener">BabelCode</a> is a C# to Delphi for .NET code conversion utility. It is extremely experimental and you shoul use it at your own risk.</p>
<p>For example, copy the following code to your clipboard and then try the <a href="http://dotnet.borland.com/babelclient/BabelClient.aspx" target="none" rel="noopener">BabelCode ASP.NET client</a>.</p>
<p><font face="Courier New"><strong>public class Foo<br />{<br />&nbsp; string s;</strong></font></p>
<p><font face="Courier New"><strong>&nbsp; public void Bar()<br />&nbsp; {<br />&nbsp;&nbsp;&nbsp; s = s.Trim();<br />&nbsp; }<br />}</strong></font></p>
