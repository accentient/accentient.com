<p>Many of our clients need to access the TFS Version Control system from VS 2002/2003, as well as other development environments including SQL Server Management Studio.&nbsp; They've been able to do this for some time, but the plug-in to support it always felt a bit clunky.&nbsp; So it is with great pleasure that I can report the new MSSCCI plug-in (available <a href="http://www.microsoft.com/downloads/details.aspx?FamilyId=87E1FFBD-A484-4C3A-8776-D560AB1E6198&amp;displaylang=en">here</a>) was released yesterday!&nbsp; In addition to improving the interface, there were several other additions, too.&nbsp; Now, database developers can access their version controlled T-SQL scripts using Enterprise Manager.&nbsp; Plus, developers can now modify work items during the check in process!&nbsp; </p>
<p>If you use the MSSCCI provider for working with TFVC, go download the new version right away!&nbsp; And, if you're looking for further cool plug-ins, don't hesitate to check our Widget's page, located <a href="http://www.teamsystemwidgets.com">here</a>.</p>
