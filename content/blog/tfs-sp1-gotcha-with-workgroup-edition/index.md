If you're upgrading your TFS with SP1 (which you should) and you're using the Workgroup edition, there's a gotcha if you already are using all 5 allowed people.&nbsp; Basically, you'll have to remove on of the users, do the upgrade, then add the user back in.&nbsp; <a href="http://blogs.msdn.com/dglover/">Dave Glover</a> has a good post you'll want to read before you do the upgrade.&nbsp; You can find his post <a href="http://blogs.msdn.com/dglover/archive/2006/12/18/upgrading-to-team-foundation-server-sp1-workgroup-version-and-a-gotcha.aspx">here</a>.&nbsp; Happy upgrading!<br />
