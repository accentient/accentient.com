<p>I was just emailed an invite to take the beta&nbsp;exams 71-330 and 71-340, Implementing Security for Applications with Visual Basic .NET and Visual C# .NET,&nbsp;respectively. <em>Update: </em>The exams do not open for Beta until April 24th thru May 4th.</p>
<p>These exam will count as elective credit towards the MCSD or MCAD certification. These are beta exams, so although the are free,&nbsp;each exam takes about 4 hours, because you're seeing all the questions that would go into the pool. Some questions will get&nbsp;tossed out before the&nbsp;exam goes live. Microsoft is planning on producing some <span class=317544803-28022004><font face=Arial size=2>associated learning products, namely a course, #2840, <strong><em>Developing Secure Applications</em></strong> and a Microsoft Press Training Kit.</font></span></p>
