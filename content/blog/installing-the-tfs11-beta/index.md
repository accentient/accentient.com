<h2>Config</h2> <p>To use the new version of TFS on a clean VM, I am going to use the following:</p> <p>VMWare Virtual Machine, 2 Proc, 2 Core 2 GB RAM</p> <ul> <li>Windows Server 2008 R2 SP1 64 bit  <li>SQL2012 RC Enterprise – the perspectives are worth it  <ul> <li>This is not officially supported but I would be surprised if it doesn’t work!</li></ul> <li>MOSS 2010  <li>TFS 11  <li>VS 11 Ultimate</li></ul> <h2>Step 1 Read the Manual</h2> <p>Download and read the install guide from <a title="http://www.microsoft.com/download/en/details.aspx?id=29035" href="http://www.microsoft.com/download/en/details.aspx?id=29035">http://www.microsoft.com/download/en/details.aspx?id=29035</a></p> <p>&nbsp;</p> <h2>Step 2 Install Windows and Pre-Requisites <div style="padding-bottom: 0px; margin: 0px; padding-left: 0px; padding-right: 0px; display: inline; float: none; padding-top: 0px" id="scid:0767317B-992E-4b12-91E0-4F059A8CECA8:228eb822-b2fb-495f-9bb2-730acdbc8554" class="wlWriterEditableSmartContent">Technorati Tags: <a href="http://technorati.com/tags/TFS11" rel="tag">TFS11</a>,<a href="http://technorati.com/tags/SharePoint" rel="tag">SharePoint</a>,<a href="http://technorati.com/tags/Install" rel="tag">Install</a></div></h2> <p>Installed from the media. </p> <p>Changed the machine name to TFS11</p> <h3>Install IIS</h3> <p>Have a look at IIS to make sure it woke up properly.</p> <h3>Add Application Services Role</h3> <p>Added this in with the hostable core. Not essential for TFS – but this will be a build server as well as a general sandpit.</p> <h3>Enable Remote Desktop</h3> <p>I know i will need it later – so I do it now.</p> <h3>Service Accounts</h3> <p>Create some service accounts. For my test machines I use the same password, picked up from Brian Randell it is the least secure password that meets Windows security "P2ssw0rd".</p> <p>Rich was using <a href="mailto:P@ssw0rd">P@ssw0rd</a> – try that on a French keyboard when you are used to a UK/US one.</p> <p> <table border="1" cellspacing="1" cellpadding="2" width="514"> <tbody> <tr> <td valign="top" width="200">Account name</td> <td valign="top" width="309">Use</td></tr> <tr> <td valign="top" width="200">svcSQL</td> <td valign="top" width="309">All SQL services</td></tr> <tr> <td valign="top" width="200">svcTFS</td> <td valign="top" width="309">TFS service account</td></tr> <tr> <td valign="top" width="200">svcMOSS</td> <td valign="top" width="309">Sharepoint and reporting account</td></tr> <tr> <td valign="top" width="200">svcTFSBuild</td> <td valign="top" width="309">Build Account</td></tr></tbody></table></p> <p>All set to user cannot change, and password never expires.</p> <p><a href="image_2.png"><img style="display: block; max-width: 100%; height: auto; margin-bottom: 1rem; border: 1px solid black; box-shadow: 2px 2px 10px rgba(0,0,0,0.5);" title="image" border="0" alt="image" src="image_thumb.png" width="244" height="237"></a></p> <h3>SQL 2012 RC</h3> <p>Install was straightforward but took a couple of hours. I installed Enterprise so that I could play with perspectives.</p> <p>Installed analysis services, reporting services, and all the tools.</p> <h3>SQL 2008 Client Tools</h3> <p>Needed to install this to be able to install MOSS 2010 SP1</p> <h3>MOSS 2010 SP1</h3> <p>Installed all the pre-requisites then MOSS 2010 with SP1. Note that MOSS 2010 is memory hungry, recommending 8GB for production</p> <p><a title="http://technet.microsoft.com/en-us/library/cc288751.aspx" href="http://technet.microsoft.com/en-us/library/cc288751.aspx">http://technet.microsoft.com/en-us/library/cc288751.aspx</a></p> <h3>TFS11</h3> <p>Straightforward install, and I then went through the Advanced configuration as I had installed all the prerequisites.</p> <p>it was quick and painless, however I did get a warning about memory. This is because SharePoint wants 8GB, and TFS needs 2 GB.</p> <p>The minimum to install is 4 GB, under that you will get blocked.</p> <p><a href="image_4.png"><img style="display: block; max-width: 100%; height: auto; margin-bottom: 1rem; border: 1px solid black; box-shadow: 2px 2px 10px rgba(0,0,0,0.5);" title="image" border="0" alt="image" src="image_thumb_1.png" width="516" height="386"></a></p> <p>&nbsp;</p> <h3>Build Agent</h3> <p>The only other noteworthy point was that I received an error message configuring the build agent:</p> <p><a href="image_6.png"><img style="display: block; max-width: 100%; height: auto; margin-bottom: 1rem; border: 1px solid black; box-shadow: 2px 2px 10px rgba(0,0,0,0.5);" title="image" border="0" alt="image" src="image_thumb_2.png" width="519" height="390"></a></p> <p>I went in to the admin console, bounced the controller and the agent and all was good.</p> <p>&nbsp;</p> <p>A very easy install and configuration, building on the great work with 2010. Great use of Wix!</p>
