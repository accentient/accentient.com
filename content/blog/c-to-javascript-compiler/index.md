Learning a new language isn't always fun, especially Javascript.&nbsp; Plus, when you're working in one language, it takes context switching to flip to another, even for a trivial task.&nbsp; Nikhil Kothari, an architect on the Web Platform and Tools team at Microsoft, has created something called <a href="http://www.nikhilk.net/Project.ScriptSharp.aspx">Script#</a>, which allows you to program in C# while compiling to Javascript/Ajax.<br /><br />ZDnet has a good <a href="http://blogs.zdnet.com/web2explorer/?p=197">blog post</a> on the importance of this technology, and a brief comparison with the Google version which compiles Java to Javascript.<br />
