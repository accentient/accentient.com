<p>Great news!&nbsp; Yahoo! has licensed the X1 desktop search engine for free download.&nbsp; I've used the Google Desktop, Lookout (free from Microsoft), and X1, which used to cost $99 for a personal license.&nbsp; X1 was by far the best.&nbsp; It's search was blazingly fast, the index was small and the UI was the simplest.&nbsp; Plus, it doesn't have the security issues of Google Desktop or the Outlook start-up time impact of Lookout.</p>
<p>I'll be downloading it as soon as it's released, comparing it to the full version of X1.&nbsp; I'll let you know how it looks.</p>
