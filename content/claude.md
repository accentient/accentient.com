Agentic AI is transforming how software teams build and deliver products. Claude Code, Anthropic's agentic coding tool for the terminal and your IDE, can reason, plan, and execute complex tasks with you in the loop, freeing developers to focus on high-value work. Our Claude Code training is a three-course series that takes you from your first session to production-grade automation, plus a combined bootcamp that delivers all three back to back.

### Claude Code Developer
Get productive with Claude Code from day one. This hands-on course covers working in the harness, driving Claude with slash commands, managing tokens and context, extending it with skills and MCP servers, and automating routine work with hooks. You'll build the habits that make Claude Code a dependable part of your daily workflow. It is the first of three courses, and no prior experience is required.

<img src="/images/icons/class.png" alt="Class" title="Training Class">&nbsp; [Claude Code Developer](/ccd/) (1 day)<br/>

### Claude Code Orchestrator
Coordinate fleets of agents instead of doing everything in one conversation. This course shows you how to break work into sub-agents and orchestrate them: defining agent roles, scoping their tools, and running them in parallel or in pipelines. You'll build multi-agent workflows hands-on and learn when delegation pays off. It picks up where the Developer course leaves off.

<img src="/images/icons/class.png" alt="Class" title="Training Class">&nbsp; [Claude Code Orchestrator](/cco/) (1 day)<br/>

### Claude Code Architect
Turn Claude Code into automated pipelines that build, verify, and correct on their own. This capstone course covers loop engineering: defining clear inputs and outputs, using tests as pass/fail gates, and constructing agentic build-verify-correct loops that run with minimal supervision. You'll engineer real loops hands-on and learn to make them reliable, bounded, and observable.

<img src="/images/icons/class.png" alt="Class" title="Training Class">&nbsp; [Claude Code Architect](/cca/) (1 day)<br/>

### Claude Code Bootcamp
Go from your first session to production-grade automation in three days. The bootcamp combines all three courses, Developer, Orchestrator, and Architect, into one guided track, with each day building on the last. Ideal for teams who want the complete path in a single week. Advanced students who have completed an individual course can join on the day that fits them.

<img src="/images/icons/class.png" alt="Class" title="Training Class">&nbsp; [Claude Code Bootcamp](/ccb/) (3 days)<br/>

All of these courses can be delivered on-site or remotely and customized to align with your team's tools, structure, and delivery goals.
